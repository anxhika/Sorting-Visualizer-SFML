# 🔢 Sorting Visualizer (C++ | SFML)

A **Sorting Algorithm Visualizer** built using **C++ and SFML**, designed to visually demonstrate how different sorting algorithms work step by step. This project provides an interactive way to understand and compare sorting algorithms through real-time graphical animations.

## ✨ Features

- Real-time visualization of sorting algorithms
- Interactive speed control using a slider
- Displays execution time for each algorithm
- Keyboard-based algorithm selection
- Reset and replay functionality
- Clean and intuitive SFML-based UI

---

## 🧮 Sorting Algorithms Implemented

| Key | Algorithm        |
|-----|------------------|
| 1   | Selection Sort   |
| 2   | Insertion Sort   |
| 3   | Bubble Sort      |
| 4   | Radix Sort       |
| 5   | Merge Sort       |
| 6   | Cocktail Sort    |

---

## 🎮 Controls

- **1 – 6** → Select sorting algorithm  
- **0** → Return to main menu / Reset  
- **ESC** → Exit application  
- **Slider** → Adjust sorting speed (delay in milliseconds)

---

## 🎨 Color Legend

- ⚪ **White** – Unsorted elements  
- 🔵 **Blue** – Currently compared element  
- 🔴 **Red** – Active comparison  
- 🟢 **Green** – Sorted elements
