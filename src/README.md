# Sorting Visualizer (SFML)

This project is a C++ based Sorting Visualizer built using the SFML graphics library.  
It visually demonstrates popular sorting algorithms such as Selection Sort, Insertion Sort, Bubble Sort, Merge Sort, Radix Sort, and Cocktail Sort.

The application shows animated bars representing array elements, includes speed control using a slider, and displays execution time for each algorithm.  
This project helps students understand sorting algorithms step by step through visualization.

## Features
- Multiple sorting algorithms
- Real-time animation
- Speed control slider
- Execution time display
- SFML-based GUI

## Technologies Used
- C++
- SFML (Simple and Fast Multimedia Library)

## How to Run
1. Open the project in Visual Studio
2. Make sure SFML is properly configured
3. Run the project (Debug/Release)
